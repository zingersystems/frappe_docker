# VS Code Example

## Purpose

- Owns reusable VS Code workspace examples for launch, task, and settings configuration.

## Ownership

- `launch.json` documents debugger launch examples.
- `tasks.json` documents task runner examples.
- `settings.json` documents editor and workspace setting examples.

## Local Contracts

- Keep these files as examples unless the user asks to make them active workspace configuration.
- Preserve valid VS Code JSON shape and avoid adding machine-specific paths unless they are clearly scoped to this dev container.

## Work Guidance

- Prefer bench-relative commands for Frappe tasks.
- Keep example names explicit about site, app, or command scope.
